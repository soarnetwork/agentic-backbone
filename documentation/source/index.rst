Project goals
-------------

- Provide a scalable backbone for agent swarm orchestration.
- Define clear integration points for skills, memory, and agent roles.
- Support enterprise-ready workflows and long-running context storage.


Quick start
-----------

1. Install documentation dependencies:
   ``python -m pip install -r requirements.txt``
2. Build the docs:
   ``make html`` or ``make.bat html``
3. Open the generated site at ``build/html/index.html``.
