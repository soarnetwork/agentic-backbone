# agentic-backbone

The SourNetwork Agentic-Backbone.

# What is it?

Well, the Agentic-Backbone is the backbone of our agentic agent application. The agent application essentially is something similar to OpenClaw, but on entireprise level, with a swarm mode.

# Features

You are able to run agents within swarm - run multiple agents in parallel, for example: One CEO, CMO, CFO, ... You can run those with our `agentic-skills` or/and our ´agentic-memory´ to store the memory / context on disk for longer periods of time.

# Requirements

We do require a fair amount of ram, 16GB is the bare minimum, this is only applicable for MacOS Hardware + Silicon. We recommend testing on an M4 Mac Mini first.
